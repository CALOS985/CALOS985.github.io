每天几分钟看懂 AI 圈发生了什么：数字生命卡兹克的 AIHOT，还可免费薅羊毛！

发布于 2026-11-23 · AI资讯

每天几分钟看懂 AI 圈发生了什么：数字生命卡兹克的 AIHOT，还可免费薅羊毛

早上想扫一眼 AI 圈，常常要在公众号、厂商博客、X 和技术媒体之间来回切换。一款模型发布后，官方公告、第三方实测和网友讨论夹在一起，刷了十几条，可能还在看同一件事。

AIHOT 是博主「数字生命卡兹克」做的 AI 资讯聚合站。 它持续采集厂商博客、媒体、X、公众号和 RSS 等信源，用 AI 筛选内容、生成中文摘要，并把围绕同一事件的报道归在一起。公开资讯打开就能看，日常浏览免费、无需注册。AIHOT 官网 · 关于 AIHOT

01｜先看精选，几分钟扫完当天要点

首页上方是「当前热点」，下方是按日期排列的「精选」信息流。精选卡片通常会给出来源、发布时间、中文摘要、AI 评分和推荐理由。摘要帮你知道发生了什么，推荐理由帮你判断这篇文章值不值得点开。想找某个模型的消息，可以搜标题和摘要，也可以按模型、产品、行业、论文等类别筛选；想看更广的覆盖范围，就切到「全部 AI 动态」。精选首页 · 全部 AI 动态

图 1｜首页把正在发酵的热点和按日期更新的精选放在同一页。

这个设计对时间最少的人尤其友好。比如，通勤时先看标题和推荐理由，等看到跟自己工作相关的更新，再打开详情页核对来源和原文。长期关注某家公司或技术方向，可以去「主题」页集中看，像 OpenAI、DeepSeek、AI 编码、图像生成都有各自的入口。主题页

02｜热点榜的亮点，是把一件事的后续放在一起

「AI 热点榜」展示过去 48 小时讨论较多的事件。AIHOT 将相关报道归为一个事件，综合站点观察到的讨论参与情况和时效计算热度。同一家机构反复发布会合并计数，较新的讨论权重更高。榜上的数字适合帮你发现值得追踪的话题，报道里的结论还要回到信源核对。AI 热点榜与计分说明

图 2｜热点榜按事件排列，能看到近期讨论强度和参与来源。

点进事件，还能看到 AI 综述、最新进展和按时间排列的报道，并按「官方一手」「精选报道」筛选。比如在截图里的 Inkling 2 Mini 事件页，可以顺着时间线找到模型发布、第三方评测和本地运行相关报道。做公众号选题时，可以先用综述梳理脉络，再去官方发布核对规格，最后看第三方评测怎么测、测出了什么。几个步骤都能从同一个事件页出发。Inkling 2 Mini 事件页

图 3｜进展和相关报道集中在同一个事件页，方便回查。

03｜不想追实时消息，就固定看日报或周报

按站点说明，AI 日报每天早上 8 点出刊，周一出周报，每月 1 日出月报。日报有头条、今日看点和分类版面，也会估算阅读时间。点左侧往期目录能回看历史，遇到需要引用的内容，可以从条目进入详情或打开原文。两三天没看 AI 新闻，可以从日报补起；给团队做一周简报，周报更适合作为筛选素材的起点。AI 日报与往期入口 · 出刊说明

图 4｜日报的版面和往期目录方便快速浏览，也能按日期补看。

04｜选模型、查额度，也有专门的工具

模型榜适合用来缩小试用范围。 榜单汇总第三方实测，分为综合、编程、科研、专业办公和知识问答等榜。除了名次，还能看已有评测的覆盖率，并切到价格视图。比如要选一个写代码的模型，可以先看编程榜和价格，再挑两三个候选，用自己手里的真实任务测试一遍。大模型排行榜

图 5｜模型榜提供任务维度、评测覆盖率和价格入口。

重置监控适合查公开的额度消息。 这一栏覆盖 Codex、Antigravity、Claude 和 Grok Bot 等产品。以 Codex 为例，页面会汇总已宣布的重置或重置卡发放消息，给出北京时间、历史日历和原帖。听说额度重置了，可以先看消息的生效时间和适用范围，然后回到自己的账户确认。额度重置监控

图 6｜Codex 重置监控把原帖、历史记录和日历放到了一起。

「Token 羊毛」适合找可试用的免费额度。 它把各家公开的免费配额、签到积分和限时活动汇总在一处。试新工具、跑小样或验证 API 时，可以先找适合的活动，再去对应平台确认资格、有效期和领取条件。页面上的人民币金额是按官方价折算的额度参考。Token 羊毛

图 7｜Token 羊毛把不同平台的公开福利集中展示。

05｜把资讯接进自己的阅读习惯

「Agent 接入」提供 RSS、Agent Skill、MCP 和 REST API。习惯用阅读器的人可以订阅 RSS；在支持 Skill 或 MCP 的工具里，可以按页面说明接入，再问「最近一周有哪些值得关注的模型发布？」；自己做资讯看板或内部简报，也可以用 API 读取。站点说明这些公开接入方式为匿名只读，无需 API Key。AIHOT 接入说明 · RSS 订阅入口

图 8｜RSS 可以接入习惯使用的阅读器，Skill、MCP 和 API 则面向不同的工作流。

如果你只想养成一个轻量的习惯，早上翻日报，遇到值得追的消息再进热点事件页，准备写稿时打开原文。 对内容创作者，这能减少找选题和补背景的时间；对产品和技术团队，它提供了一条从了解行业动态到筛选候选工具的路径。信息太多的一天，先知道该点开哪几篇，就已经省下了不少时间。
