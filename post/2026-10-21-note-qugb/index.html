我做了一个沃尔玛关键词分析看板：把广告报表变成优化行动清单

作者：卡洛斯

在线体验：沃尔玛关键词分析看板

做沃尔玛广告复盘时，拿到报表只是开始。

真正需要花时间的，是从大量搜索词、商品和广告活动中找出值得处理的问题：哪些词带来了订单，哪些词已经花钱却没有转化，哪些词整体表现普通，但在某个商品或匹配方式下其实有机会。

如果每次都要重新筛选、做透视表、计算指标，再把结果整理成优化清单，分析过程就很容易变成重复劳动。

所以，我做了这个沃尔玛关键词分析看板。导入沃尔玛广告后台导出的报表后，就能在同一个页面里查看整体表现、逐词诊断、自动广告搜索词分级和低花费机会，并把结果导出来继续复盘。

我希望它能帮运营更快地回答一个问题：下一步，应该优先看哪些词，以及为什么？

图 1｜看板首页：集中查看核心指标，并对比四组广告的花费、销售与回报。

文中界面截图均来自在线版看板，使用看板自带的虚构示例数据，仅用于展示功能，不代表真实广告投放效果。

一、这个看板适合用来做什么？

看板面向需要分析沃尔玛广告报表的卖家、广告运营和服务商，尤其适合以下几类工作：

  • 日常复盘：快速了解本次报表范围内的花费、销售、订单和广告回报。
  • 逐词排查：从表现优秀、0 订单复盘、效率待提升等分类中定位重点。
  • 自动广告挖词：筛选值得进一步复核、测试精准投放的搜索词与商品组合。
  • 商品或活动复盘：查看同一个词在不同商品、广告活动和匹配方式下的表现差异。
  • 整理交付物：导出分析报告、优化行动清单，或保存一份可离线打开的看板。

整个使用流程可以概括为：

导入报表 → 看整体表现 → 定位重点关键词 → 拆分查看原因 → 人工复核 → 导出执行清单。

二、五个模块，分别解决哪些问题？

1. 表现总览：先看清广告花费去了哪里

打开看板后，「表现总览」会展示六项核心指标：广告花费、归因销售额、广告回报 ROAS、归因订单、广告点击和订单转化率，并补充 CPC、CPA、CTR、ACOS 等参考信息。

除了总数，还可以查看：

  • 自动广告、手动广泛、手动词组、手动精准四组广告的指标明细。
  • 有订单组合与 0 订单组合分别消耗了多少花费。
  • 自动广告与手动广告的整体表现差异。
  • 不同匹配方式的花费、销售、订单及回报。
  • 带来销售的关键词，以及关键词机会分布图。

机会图把花费与 ROAS 放在同一张图上，气泡大小表示订单数，便于找到需要进一步查看的关键词。它提供的是当前报表的分布视角，不是时间趋势。

顶部筛选支持商品、广告类型、匹配方式和广告活动，相关指标会随筛选条件重新计算。既可以看整体，也可以聚焦某一个商品或某一类广告。

2. 关键词诊断：让每个词都有可追溯的复盘线索

「关键词诊断」支持在搜索词和投放词两个分析维度之间切换。搜索词用于查看用户实际搜索的词，投放词用于查看报表记录的投放关键词；报表中的未知值会保留，不会被推断成已经设置的关键词。

看板会根据当前规则，对关键词进行分类，并叠加维度标签。

分类或标签 帮助发现的问题
表现优秀 达到所设回报与样本条件，值得优先复核增长机会
0 订单复盘 已有一定花费和点击，但暂时没有订单，需要检查原因
匹配可优化 同一个词在不同匹配方式下，存在达到样本门槛后的表现差异
商品可优化 同一个词在不同商品下，存在达到样本门槛后的表现差异
活动可优化 同一个词在不同广告活动下，存在达到样本门槛后的表现差异
效率待提升 已有订单，但回报低于设定标准，需要进一步复盘
继续观察 尚未优先归入其他主分类，仍需积累或检查证据

图 2｜关键词诊断：分类标签与关键指标放在同一张表中，方便确定复盘顺序。

点击具体关键词，可以打开详情，分别查看匹配方式、商品、广告活动的拆分表现，以及对应的投放词记录。

图 3｜关键词详情：展开单个搜索词，查看汇总指标和拆分表现；图中展示匹配方式拆分，继续下滚可查看商品、活动和投放词。

这一步的价值，在于避免只凭一个汇总 ROAS 判断整个词。同一个搜索词可能适合某个商品，却不适合另一个商品；也可能在精准匹配下表现较好，在广泛匹配下表现较弱。

需要注意，主分类有优先顺序，维度标签可以叠加。「多维诊断」会按设置检查命中的维度数，因此不同标签的数量不能直接相加。

3. 自动广告深挖：把搜索词整理成不同优先级的候选

自动广告里产生订单的搜索词，通常值得进一步查看，但是否适合迁移或测试，还需要结合商品和样本判断。

「自动广告深挖」以搜索词 × 商品为单位汇总自动广告表现，避免把一个词在不同商品下的结果混为一谈。

默认分级如下，门槛可以自行修改：

分级 默认条件 复盘方向
Tier 1 · 已验证 ROAS ≥ 3，且订单 ≥ 2 优先评估精准投放机会
Tier 2 · 有潜力 ROAS ≥ 3，但订单 < 2 作为小额测试候选，继续确认样本
Tier 3 · 待优化 1.5 ≤ ROAS < 3 复核相关性和表现后决定是否继续测试
Tier 4 · 观察池 ROAS < 1.5，或没有花费而无法计算 ROAS 优先验证相关性与样本情况

图 4｜自动广告深挖：以“搜索词 × 商品”为单位分级，整理值得进一步复核的测试候选。

这里的 Tier 是本看板定义的分析分级。「已验证」表示达到了设定门槛，不代表已经证明长期盈利，也不是沃尔玛官方对关键词的评级。

在调整投放前，仍需要检查搜索词与商品是否相关、是否已有相同投放，以及当前观察周期是否足够。

4. 低花费潜力：给小样本机会留一个观察入口

只按销售额或花费排序，容易把注意力集中在大词上。一些花费较少、已有初步转化或点击信号的词，则可能被排在后面。

「低花费潜力」会在当前筛选范围内，先按「搜索词 × 商品」合计不同广告记录的花费，再筛选进入潜力池的组合。默认低花费上限为 10 美元，可以按业务情况调整。

潜力池分为四类：

  • 已转化潜力：已经产生订单，并达到设定的 ROAS 门槛。
  • 高点击意愿：CTR 和点击样本达到设定条件，值得继续检查。
  • 待验证：曝光不足，或点击表现尚可，但证据仍不充分。
  • 低优先级：当前点击表现和相关性需要进一步复核。

图 5｜低花费潜力：汇总当前筛选范围内的组合花费，保留值得继续观察的小样本机会。

这个模块更适合用来建立后续观察或测试名单。高 CTR 反映点击意愿，不能直接证明转化能力；低花费下出现一笔订单，也不能直接推导出放大投入后的表现。

5. 数据与口径：让分析规则适配自己的业务

不同商品的毛利、价格和观察周期不同，很难始终使用同一套判断门槛。

在「数据与口径」中，可以分别设置关键词诊断标签的条件，包括 ROAS、订单、花费、点击门槛，以及多维诊断至少需要命中几个维度。各项规则还可以单独启用或关闭。

自动广告分级和低花费潜力池使用另一组可调阈值，与关键词诊断规则独立设置。有效修改会重新计算，页面也会显示实际生效的条件。

图 6｜规则设置：各类标签可以分别启用或关闭，并调整对应门槛；卡片同时显示实际生效的条件。

规则支持导出、导入 JSON 文件。这样可以保存适合某类商品的分析口径，或在团队中共享相同的判断标准，规则文件本身不包含广告数据。

三、第一次使用，按这六步操作

第一步：打开看板，先熟悉示例数据

访问 沃尔玛关键词分析看板。

首次打开会显示随机生成的虚构示例数据，可以先体验筛选、分类和关键词详情。这些商品与广告表现仅用于演示，不是实际经营案例。

第二步：准备沃尔玛广告报表

在沃尔玛广告后台的 On-demand Reports 中，导出 ItemKeywordPerformance 报表，使用 CSV 文件导入。

建议保留原始字段名，不要将其他报表直接改名后导入，也不要先删除不熟悉的列。如果只有 Excel 工作簿，需要先保存为 CSV。

导出时记下报表统计周期，确保后续复盘知道这批数据覆盖哪段时间。看板不会根据文件名猜测统计周期。

第三步：点击「导入报表」

选择文件后，看板会检查必要字段、记录结构和数值是否合法。成功导入后，会显示来源文件、记录数量及相关分析结果。

一次导入会替换当前数据，不会自动追加到旧报表。 如果需要分析合并数据，应先在外部核对统计范围，避免同一批记录重复计入。

第四步：先筛选，再查看整体和重点词

可以先按商品、广告类型、匹配方式或活动缩小范围，也可以搜索关键词、商品 Item ID、广告活动名称或活动 ID。

数字搜索支持完整或部分商品编号；能够识别的活动名称或 ID 搜索会联动活动筛选。遇到与实体搜索冲突的旧筛选条件，页面会进行调整并提示。

随后从「表现总览」了解整体结构，再到「关键词诊断」查看需要优先处理的词。

第五步：调整规则，复核具体组合

进入「数据与口径」，把默认门槛调整为适合当前商品和观察周期的标准。

再回到诊断结果，点击关键词查看拆分明细。对于自动广告候选和低花费词，重点检查具体商品、相关性和样本，不要只看分类名称。

第六步：导出结果，保存本次分析

图 7｜数据管理：导入报表、下载离线看板、备份数据，以及单独导入或导出规则。

导出内容 适合的用途
关键词诊断报告 CSV 整理当前筛选下的指标、分类、维度标签和建议
优化行动清单 CSV 汇总需要复盘的关键词和自动广告精准测试候选
自动广告清单 / 潜力词清单 分别建立自动广告与低花费组合的观察、测试名单
原始记录 CSV 保留当前筛选范围或指定关键词的底层记录
数据备份 JSON 保存数据与分析设置，供后续通过「恢复 JSON」重新载入

数据备份与规则备份用途不同：恢复数据使用「恢复 JSON」，加载规则使用「导入规则JSON」。

四、一个例子：整体表现一般的词，该怎么处理？

假设某个搜索词整体 ROAS 不高，但在样本达到设定门槛后，按商品拆分出现以下结果：

商品 ROAS
商品 A 5.2
商品 B 1.1
商品 C 0.7

以上为说明分析思路的虚构示例，不是实际投放结果。

仅凭汇总值，可能会得出“这个词整体不值得继续”的判断。看到拆分结果后，更有用的问题是：

  • 商品 A 的转化表现是否稳定，是否值得继续测试？
  • 商品 B、C 与搜索需求的匹配程度如何？
  • 三个商品的价格、详情页、匹配方式和广告活动是否存在差异？

看板把值得追问的组合呈现出来，后续再由运营结合商品与账户情况判断原因、安排动作。

五、我认为，这个看板的意义有三点

第一，减少重复整理，把时间留给判断。 把常用的指标汇总、分类和拆分放在同一套流程里，复盘时就可以更快地进入具体问题。

第二，让建议有依据，也能回看依据。 分类结果对应明确的规则，关键词详情对应底层拆分数据。看到一个标签后，还能继续检查它为什么出现，而不是只接受一句笼统的建议。

第三，让分析更容易进入执行和协作。 通过 CSV、规则文件和离线看板，可以把发现整理成待复核清单，保留当时的分析口径，也便于团队沟通。

它的价值，是帮助运营建立更清晰的处理顺序：先确认范围，再找重点，最后回到具体组合做判断。实际效果仍取决于数据质量、观察周期和后续执行。

六、使用前，了解这些口径会更有帮助

指标按汇总结果重算

看板会使用合计值重新计算比率，而不是直接平均各行的 ROAS、CTR 或 CVR。

  • ROAS = 归因销售额 ÷ 广告花费。
  • ACOS = 广告花费 ÷ 归因销售额。
  • CTR = 点击 ÷ 曝光。
  • CVR = 订单 ÷ 点击。
  • CPC = 广告花费 ÷ 点击。
  • CPA = 广告花费 ÷ 订单。

例如，两个组合分别花费 50、150 美元，归因销售额分别为 250、150 美元，合计 ROAS 应为 400 ÷ 200 = 2，不能把各自的 5 和 1 直接平均成 3。分母为 0 时，看板显示「—」。

这里的销售额是广告归因销售额，不等于店铺总销售额；ROAS 也不等于利润率。判断是否盈利，仍需要结合商品成本、平台费用和其他经营支出。

页面导入与本地保存是两回事

看板本身在浏览器页面内存中处理导入的报表，不会主动把报表上传到站点服务器，也不会自动把广告记录保存到浏览器数据库。

刷新或重新打开在线页面，会回到示例数据。希望保留本次分析时，需要主动下载数据备份 JSON 或独立 HTML；规则设置则可以保存在当前浏览器中。

导出的 HTML 和数据备份 JSON 会包含当前广告数据，分享文件前应先确认内容。规则 JSON 不包含广告数据，适合单独共享分析标准。

分析结论受报表范围和样本限制

当前版本针对这类报表提供关键词与组合分析，不提供基于日期的趋势、环比分析，也不会在缺少预算、实际竞价或搜索曝光份额时推断相关空间。

0 订单花费表示值得复盘的记录，不能直接等同于可节省金额。报表归因是否成熟、商品近期是否发生变化，也需要结合后台信息核对。

看板不会自动调整广告账户。分类和建议用于辅助复盘，具体的加词、调价、否定或其他投放动作，需要由运营自行确认和执行。

如果你也在做沃尔玛广告，可以先用示例数据熟悉页面，再导入自己的报表，看看哪些词、哪些组合值得优先关注。
