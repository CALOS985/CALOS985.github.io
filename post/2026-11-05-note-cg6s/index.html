B站怎么全是“大肥鱼”？看完这些梗，教你把 DeepSeek 接进 DSH

以前刷 B 站，怕自己一不留神刷到凌晨。现在再看评论区，发现替人刷视频的 AI 已经先到了：头像是蓝发鲸鱼娘，开口是“本鱼”，干完活还惦记着回家吃白饭。

人类还在收藏教程，鱼已经开始交日报了。

这股“养鱼”热潮背后，是 DeepSeek Harness，简称 DSH。它能接入模型、处理文件和执行任务，还能安装社区插件，把桌宠、QQ 聊天、视频筛选接进来。先看几张名场面，再把自己的第一条鱼养起来。

01｜评论区闹鱼灾，Token成了鱼粮

最近这批“大肥鱼”账号，最有辨识度的地方，是连讨论技术都带着鱼味：一边说 Agent 和待办清单，一边自称“本鱼”。

图 1｜大肥鱼人设出现在技术讨论和评论互动中

本来是让 AI 帮忙读资料，最后读出了一种“电子同事也在摸鱼”的感觉。更好笑的是，网友已经给模型调用成本安排了新名字：鱼粮。

图 2｜Token消耗被网友玩成“鱼粮吃完了”的梗

你看它端着碗挺可爱，账单可不会因为可爱就自动打折。聊天、生成报告、分析视频时，都可能发生模型调用；桌宠播放一个本地动画，则是另一回事。

图 3｜网友把模型的思考过程做成了角色表情梗

这套形象来自社区创作，并不是 DeepSeek 官方吉祥物。蓝发、鲸尾、女仆装让一个抽象模型变得好记，再加上人设提示词，就有了大家熟悉的“蓝色大肥鱼”。

不过，头像相同不代表每个账号背后都是机器人。真正值得自己上手的，是这套玩法背后的工具链。

02｜先分清：模型、DSH和桌宠各管什么

DeepSeek 模型负责理解和生成内容；DSH 是让模型使用工具、管理任务的运行环境；插件再给它增加具体本领。

dsh-pet 负责桌宠动画、互动和工作状态展示。@tencent-connect/dsh-qqbot 把 DSH 的对话接到 QQ。c1overzz/dsh-bili-scroll 则负责按偏好找视频、读字幕和整理结果。

所以，装好一只桌宠，不会自动获得刷 B 站或回复 QQ 的能力。先把模型接通，再分别安装需要的插件，出问题也容易知道该查哪一层。

下面以 Windows 官方桌面端为主线。使用 Apple 芯片 Mac 的读者，下载对应的 macOS 包；命令启动的 Web 版放在后面作为备选。

03｜第一步：安装官方DSH桌面端

在 DeepSeek 官网进入 Harness 页面，选择“下载桌面端”。Windows 选 Windows（64 位），Apple 芯片 Mac 选对应的 macOS 版本。

图 4｜Harness官网提供桌面端下载入口

下载后运行安装程序，按提示完成安装并启动。GitHub 上的 Source code 是源码包，不是给普通用户双击安装的程序。

首次打开，按客户端提供的入口登录账号或配置模型。先建一个空的测试文件夹，例如在“文档”中创建 DSH练习，把它选作工作区。后面的文件练习就放在这里。

已经习惯命令行、想使用 Web 版的读者，可以安装 Node.js 后，按官方 README 执行：

npx @deepseek-ai/dsh web

首次使用会下载所需程序，启动后默认打开本机的 3080 端口页面。使用这条路线时，运行终端需要保持开启。

桌面端和 Web 版的插件配置分开：桌面端对应 desktop，Web 版对应 web。后面如果使用命令安装插件，别选错这一项。

04｜第二步：接入DeepSeek，先让模型说话

如果客户端已通过账号登录且能正常回复，可以直接做下面的测试任务。需要使用 API Key 时，按这条路径配置。

进入 DeepSeek 开放平台，在 API Keys 页面创建自己的密钥，并确认账户有可用额度。API 调用按用量计费，聊天网页能用，并不代表 API 账户已有余额。

回到 DSH，打开“设置 → 模型”，找到 DeepSeek 卡片，在 API key 输入框中填入密钥，再点击 Apply（应用）。

图 5｜在模型设置中填写DeepSeek API Key并应用

直接使用内置 DeepSeek 提供商时，先沿用默认地址和模型目录，不必照搬别人的第三方中转配置。保存后回到新会话，在输入框旁的模型选择器里选一个当前可用的模型。

先发一句普通消息，确认它能正常回复，再复制下面这个文件任务：

请在当前工作区新建“养鱼练习”文件夹，在里面创建一份“今日计划.md”。
内容包括：今天要学的一个AI工具、预计投入的时间、完成后怎么检查。
只操作这个文件夹。完成后告诉我文件保存在哪里。

按提示确认工作区内的文件操作。等它完成，自己打开文件看一眼：内容是否存在，位置是否正确。做到这一步，模型接入和基本工具链就跑通了。

密钥保存成功只是配置完成，能收到回复、能完成指定文件任务，才是这轮练习的完成标志。密钥也别放进准备发公众号的截图里。

05｜第三步：安装桌宠，让大肥鱼住进来

打开 DSH 的“插件”或“插件管理”，点击添加插件，在安装框里输入：

dsh-pet

核对项目作者为 PC2005-cloud，安装完成后彻底退出并重新打开 DSH。只刷新页面，可能没有重启持有插件的进程。

图 6｜桌宠插件让大肥鱼显示在Harness界面中

作者提供的运行界面里，大肥鱼已经出现在对话区域上方。你可以先点击、拖动它，再右键查看动作或对话入口。

插件支持待机、走动、玩耍等动画，也能跟随 DSH 的任务状态变化。想让它显示在独立桌面窗口中，再检查桌宠显示配置；首次启用可能还需要下载 Electron 运行组件。

想通过命令安装，桌面端使用：

npx @deepseek-ai/dsh plugin --profile desktop add dsh-pet

Web 版则把 desktop 换成 web。安装后重启对应的 DSH 进程。

第一次别急着装满一整片鱼塘。让这一只跟着刚才的文件任务动起来，先确认它显示正常、能互动，再继续加功能。

06｜进阶一：用官方插件接入QQ

想在 QQ 里跟它对话，可以使用腾讯连接团队发布的 @tencent-connect/dsh-qqbot。按作者推荐的桌面端流程，全程可以在应用里操作。

第一步，左侧“插件 → 添加插件”，输入下面的包名，安装并启动：

@tencent-connect/dsh-qqbot@latest

图 7｜添加并启动QQ机器人插件

第二步，点击左下角头像进入设置，找到“QQ 机器人”，用手机 QQ 扫描自己页面上生成的二维码，按手机提示完成连接。

图 8｜QQ机器人设置提供扫码绑定和访问控制

这张示例图的二维码已经做过模糊处理，操作时使用你自己客户端生成的二维码。

第三步，在绑定流程提供的机器人聊天入口发一句“你好”。需要放进群聊时，再按绑定页面提供的方式添加，并检查“群聊需要 @机器人”的设置，用一次 @ 测试回复。

刚开始建议仅允许自己的账号或测试群使用。这里接入的是能调用工具的 Agent，不只是一个表情包自动回复器。

想给它加一点鱼味，可以在对应的群聊或私聊提示词中写：

你可以自称“本鱼”，语气轻松，偶尔用一句短玩笑。
回答问题时先把事情讲清楚，玩梗不要影响操作说明。
完成任务时说明实际结果；没有完成就说明卡在哪里。

先把消息收发跑通，再加人设。否则你问它为什么不回复，它连甩锅的机会都没有。

07｜进阶二：让它替你筛B站视频

“鱼灾”背后的一条实用路线，是让 AI 按关键词找视频、读字幕、整理值得看的内容。这里介绍作者 c1overzz 的 dsh-bili-scroll，不要与同名改版混用安装说明。

截至本次核对，作者 README 提醒 npm 包仍停在旧版，更新应从作者的 Releases 获取。可以在 DSH 对话框中直接交代：

请阅读 c1overzz/dsh-bili-scroll 的官方README和最新Releases。
为当前DSH桌面端选择兼容的安装包，并安装到desktop profile。
优先使用作者Releases中的.tgz包，不要用已标明过时的npm包。
完成后告诉我是否需要重启、设置入口在哪里。
不要开启自动评论、回复评论或私信双向功能。

如果手动安装，就在作者 Releases 下载最新的 .tgz 插件包，保持压缩状态，按 README 的命令把安装包地址或本地路径交给对应 profile。桌面端选 desktop，Web版选 web。安装完成后重启 DSH。

接着打开“设置 → 刷B站”。先到“高级”里的“环境与账号”安装主依赖，再用手机 B 站扫码登录。旧版本可能把这些设置放在独立的“环境与账号”页签里，按字段名称找即可。

“互动”页把评论和私信单独放在一起，可以按需要分别开关。

图 9｜互动页分别控制自动评论、回复评论和私信双向功能

图中“回复评论”和“私信双向”已开启。首次练习先关掉这两项，保持“自动评论”关闭，完成手动视频筛选后再决定是否启用互动。

首次先配置三件事：关注关键词、较小的视频数量，以及日报或结果的保存方式。比如关键词填“AI工具”“Python入门”，先手动跑一轮，不急着开启全天定时任务。

图 10｜在偏好设置中填写视频关注关键词

截图中展示了“科技和AI”这类偏好写法。新版本把人设、关注关键词等放在“偏好”页签；“互动”页签单独管理评论和私信功能。

点击“现在跑一轮”，等它完成后检查视频列表、单条结论与日报。抽一两条视频自己核对，再决定要不要让它定时执行。

没字幕的视频，可能需要本地转写和额外模型资源。先把有字幕的视频筛选跑通，会省下不少安装时间。自动评论保持关闭，也照样能用它找内容、看总结。

鱼先学会替你挑片，再考虑别的才艺。

08｜鱼不动、话不回，先查这几处

没有回复：先回 DSH 主界面测试模型，检查密钥、余额和模型选择。主界面也不回，就先处理模型接入。

插件装了却没出现：确认安装的是当前正在用的 profile，然后真正退出并重开 DSH；只关窗口时，也检查托盘进程是否仍在运行。

界面里有鱼，桌面上没有：检查桌宠的显示位置和 Electron 组件下载状态，不需要重新安装整个 DSH。

刷视频卡住：先手动跑一轮，查看依赖安装、扫码状态和插件诊断信息。作者记录过桌面版自动运行卡住的反馈，不要连续重复创建定时任务。

花费涨得快：先停自动任务、私信双向和持续聊天，再看模型用量。动作动画、后台筛视频和对话调用是不同的开关，别一口气全开。

第一次养鱼，完成“模型能回复、文件能生成、桌宠能显示”就已经够用了。QQ 和 B 站都可以慢慢接。鱼可以很可爱，今天要做的事也别忘了让它干。
